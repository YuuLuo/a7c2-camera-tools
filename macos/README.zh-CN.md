# A7C II macOS 相机工具

[English](README.md)

准备 macOS、Python 3.10 或更新版本，以及首次安装依赖所需的网络。将未经修改的 A7C II 官方 2.01 DAT 放在 `run.command` 同目录，命名为 `ILCE-7CM2-v2.01-BODYDATA.DAT`。相机设为 USB 海量存储、USB LUN **多个**，使用相机格式化的 exFAT 照片卡和电量充足的电池。

打开 `run.command`，选择中文或英文，再选**安装或继续**。启动器会创建独立 Python 环境并安装依赖，包括 libusb；macOS 不需要 Zadig 驱动。界面仅在需要操作相机时暂停，按机身序列号把备份、日志和续跑状态存到 `mac_service_readonly/runs/<序列号>/`。

可选择 FL2/FL3、仅电子快门音效或两者组合。音效可以直接使用机内原声而不提供文件，也可以提供不超过 2 秒的 MP3/WAV，并为自定义音频设 1–100% 响度。机内原声保持原响度。仅音效路径在冷启动后核对版本，不写 FL2/FL3 颜色属性。

功能选择后还可选择**跳过 NTSC 开机提示**（默认保留），可与上述任一功能组合，并随本机计划保存。仅跳过两处已选中的 NTSC 提示路径，不改变 PAL/NTSC 设置；已有工作目录继续使用原选择。本次 DAT 移植已通过离线验证；2026-11-08，一位 A7C II 用户在 QA 后反馈改装正常工作。详细实机测试覆盖范围和恢复能力仍未验证。详见 [NTSC 补丁说明](../native/NTSC.md)。

机身起始版本为官方 2.01。临时版本门控会使更新确认页显示 **1.99 → 2.00**；只有看到这两个数字才执行更新。最终核对完成前保留 `runs` 目录和官方 DAT。
