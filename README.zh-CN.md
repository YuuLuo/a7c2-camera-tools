# A7C II 相机工具

[English](README.md)

面向 Sony ILCE-7CM2 的研究与可复现固件工具。安装器从用户提供、未经修改的官方 2.01 DAT 构建版本号为 2.00 的安装包；之后仍可走正常的官方 2.01 更新路径。

## 功能

| 选择 | 固件改动 | 更新后处理 |
| --- | --- | --- |
| FL2/FL3 | 启用两个创意外观、回放图标和照片元数据 | 写入 CP 运行时颜色表并核对两份 BK4 |
| 电子快门音效 | 启用拍摄声音路径与两项声音菜单 | 使用机内原声或用户音频；不改 FL2/FL3 颜色属性 |
| 两者组合 | 在同一个 DAT 中合并两组改动 | 完成 FL2/FL3 颜色步骤并试听音效 |

音效可直接选用机内原厂样本，保留原响度，不需要上传文件。自定义音效支持不超过 2 秒的 MP3/WAV，并可设 **1–100%** 响度。

功能选择后还可选择**跳过 NTSC 开机提示**（默认保留），可与上述任一功能组合，并随本机计划保存。仅跳过两处已选中的 NTSC 提示路径，不改变 PAL/NTSC 设置；已有工作目录继续使用原选择。本次 DAT 移植已通过离线验证；2026-11-08，一位 A7C II 用户在 QA 后反馈改装正常工作。详细实机测试覆盖范围和恢复能力仍未验证。详见 [NTSC 补丁说明](native/NTSC.md)。

## 实现原理

1. 相机以 USB 海量存储模式（`054C:0E8A`）连接。主机完成认证并切到服务模式（`054C:0336`），使用 Jiritsu 文件命令。
2. 程序把受限的 AArch64 工作文件暂存到机身 Work 区，通过服务命令设置预加载入口并触发子进程。动态加载器执行工作文件；主机核对带版本和校验的结果、清除预加载入口，确认 USB 返回普通模式。实现见[服务探针](windows/runtime/core/sony-service-research/)。
3. 只读采集 p1 和两份 BK4，建立本机基线。构建所选 2.00 DAT 后进行整包解密校验，写入照片卡并整包回读哈希。临时 p1 补丁放开更新版本门控，机身更新后恢复原始 p1。
4. FL2/FL3 补丁接通机身已有的模式路径，并加入四行从 FX2 格式功能参数转换的颜色属性。音效补丁接通机内已有的 KindID 3 快门声；自定义模式还扩展 `SYSSOUND.BIN`，同步修改主应用与启动覆盖模块中的声音登记。

A7C II 2.01 已有 FL2/FL3 菜单资源和共用处理代码。本项目接通缺失映射并提供颜色参数，没有移植 FX2 的整个成像程序。

## 运行

| 平台 | 入口 |
| --- | --- |
| Windows 10/11 | [windows/run.bat](windows/run.bat) · [准备说明](windows/README.zh-CN.md) |
| macOS | [macos/run.command](macos/run.command) |

用户需在启动脚本同目录放入自行取得的官方 2.01 DAT。两端都是固定画面的中英双语界面，并按机身保存续跑记录。流程已在 Windows 10、Windows 11、macOS 及国行、日版机身上运行。

仓库包含项目代码、补丁描述和驱动文件，不收录索尼固件、机身采集数据、生成的 DAT、用户音频或运行日志。项目原创代码采用 [GPL-3.0-only](LICENSE)；其他组件见[许可与来源说明](THIRD_PARTY_NOTICES.md)。

通用性测试在近 10 台 A7C II 相机上测试全部通过，未出现启动异常情况。但非官方固件仍可能影响保修或导致相机无法启动，**若不愿承担相关风险，请不要使用此工具。**请保留本机备份并使用电量充足的电池。若没有独立验证与恢复能力，不要改动固件偏移、哈希、内存访问或写入步骤。
